# 遥控器鼠标模式产品规范

## 范围

当前源码候选只用于 macOS 小米 HID 路径。苹果遥控器继续使用原触摸控制；Chromecast、手机、Web 与 Windows 不提供此动作。

## 操作

- 按键页“系统与媒体”增加“切换鼠标模式”，可绑定方向键、确定键之外的普通按键；推荐菜单键长按，沿用普通键 550 ms 长按阈值。默认不绑定，不修改用户已有应用切换或截图动作，语音键不参与手势判定。
- 开启状态仅属于触发动作的那只遥控器。方向键按下立即移动系统指针，按住持续移动并有界加速，松手立即停止；相反方向互相抵消，斜向速度不大于同速单方向。
- 确定键每次真实按下提交一组左键按下/释放；重复报告不重复点击，连续完整按下/释放允许快速点击。鼠标模式临时接管方向键和确定键，不执行其原有单击、双击、长按或连发。
- 其他普通按键保持原映射。进入 App 切换器时退出鼠标模式，恢复方向选择、确定确认与返回取消，释放原有 Command 状态。
- 再次执行切换动作退出；保持原映射不变。退出时仍按住的鼠标控制键必须先松开，不能转换为旧映射或补发迟到动作。
- 断线、停止监听、配置变更、编辑捕获、打开其他运行时控制面板、权限失效、系统挂起与 App 退出必须停止移动。重连和重新启动默认为普通映射；旧计时器不能影响新会话。
- 页面内显示鼠标模式开启状态及方向键、确定键与退出方法。通过现有输入监控和辅助功能授权入口恢复权限；不新增弹窗。

## 隐私与验证

只调用 macOS 公开 CGEvent 鼠标接口，保留系统原生光标；不读取目标 App 的输入内容、文件、配置或私有协议。日志只含进程内操作号、阶段、计数、耗时与原因，不记录设备身份或鼠标坐标。事件提交不等于目标 App 已执行，日志明确标记目标结果未知。

自动化、生产 UI 截图和构建只证明各自边界。真实遥控器、系统权限、最终点击、速度、多显示器与语音基线验收前保持候选，不发布或宣称兼容；具体矩阵见[测试手册](../../Testing/ButtonMouseMode.md)。
