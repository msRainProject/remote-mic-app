# 小米遥控器鼠标模式测试

## 适用范围与准备

- 源码候选分支：`codex/xiaomi-mouse-mode`，开发基线 `0fbe8e359ddeb44081c13099544a21293bc957dd`；当前 macOS 功能，未发布，Windows 未实现。
- 准备真实小米遥控器 2 / 2 Pro（RC001 / RC003）、已安装的签名公证测试包、两个可辨认的遥控器及可选多显示器。自动化使用 HID 报告回放和注入的鼠标输出，仅验证路由与取消，不会操作真实指针。
- macOS 输入监控、辅助功能权限已授予，开启“自定义按键映射”。记录原有应用切换和截图绑定，确认它们在测试前可用。
- 正式分发测试包仍需 Developer ID 签名、公证和 staple；本地临时构建不代表这些发行门禁通过，不能把 `.build` 产物作为普通用户分发包。

## 逐步操作与失败判定

| 步骤 | 操作 | 预期结果 | 失败判定 |
| --- | --- | --- | --- |
| 默认关闭 | 未绑定切换动作，测试方向、确定、菜单、TV 与截图 | 全部保持原映射，无鼠标移动 | 升级自动启用、改写绑定或方向改变 |
| 设置入口 | 按键页选择小米设备，菜单键“长按”中选“系统与媒体 → 切换鼠标模式” | 保存此绑定；已有单击/双击及其他键不变 | 原截图或应用切换绑定被覆盖 |
| 绑定边界 | 分别编辑方向键、确定键、音量加减键及苹果 / Chromecast 设备 | 不提供切换鼠标模式，避免无法退出或错误声明支持 | 保留不可退出的切换绑定或在不支持的硬件出现动作 |
| 普通模式菜单 | 模式关闭时短按菜单；有双击绑定时再双击 | 仍执行原单击/双击，不切换模式 | 误切换或原动作丢失 |
| 开启 | 长按菜单至少 550 ms 并松开 | 切换一次，状态显示开启，松手不执行单击 | 提前切换、重复切换或额外截图 |
| 首次移动 | 第一次短按每个方向 | 按下即移动，方向正确，细小位移适合定位 | 首次不动、等待长按、反向或方向键进入目标 App |
| 持续移动 | 每个方向按住 2 s 并松开 | 平滑有界加速，松手停止 | 跳跃、卡住、停止后继续移动 |
| 滚轮单按与连发 | 指针置于可滚动窗口，单按＋/－，再分别按住 2 s 并松开 | ＋向上、－向下；首次按下立即滚动，350 ms 后每 100 ms 连续滚动，松手停止 | 方向反转、系统音量改变、误打开 App、松手后继续滚动 |
| 滚轮组合与移动 | 同时按住＋/－；松开其中一键；在滚动中按方向、松方向，再松加减键 | 两个滚轮方向抵消，松开后恢复剩余方向；移动与滚动互不误停 | 相反方向仍持续滚动、计时器串用或停止另一种操作 |
| 滚轮退出与恢复 | 按住加减键时长按菜单退出，松开；再测试原音量、双击 App 和长按 App 绑定 | 退出即时停止，旧释放不补发；普通模式恢复全部原绑定 | 退出后滚动、补发音量/应用动作或原绑定丢失 |
| 组合方向 | 左右/上下同时按；两个垂直方向同时按 | 相反方向抵消；斜向速度有界 | 相反方向失控或斜向突增 |
| 点击 | 在安全测试窗口点确定，重复原始报告，再快速按 8 次 | 每个真实按下/释放只点击一次，重复报告不点击 | 多发、漏点、Return 输入或按住重复 |
| 菜单右键 | 开启模式，在安全窗口短按菜单；按下保持 100 ms 再松开；重复原始报告和快速短按 8 次 | 按下不点击，松开后每次单击只提交一次右键；原菜单单击不执行，原绑定不改写 | 提前右键、多发、漏点、仍发送键盘菜单动作或改写绑定 |
| 菜单手势边界 | 分别短按 549 ms、长按至少 550 ms；另设菜单双击动作后单击和双击 | 549 ms 松开为右键，长按只切换一次；有双击绑定时单击等待 300 ms，双击只执行原动作 | 长按附带右键、退出误点、双击既执行原动作又右键 |
| 菜单退出绑定 | 用菜单单击切换；再改为菜单长按切换 | 显式菜单单击切换仍可退出且不右键；改为长按后单击右键 | 开启后无法退出或切换同时点击 |
| 菜单取消与旧回调 | 菜单按住/单击待定时断线、挂起、编辑映射、打开常用语或退出模式；恢复再短按 | 取消不产生右键或旧动作，恢复第一次短按可右键；旧双击/长按回调不影响新会话 | 恢复前误点、旧释放补发或提前触发新手势 |
| 退出恢复 | 移动中同时长按菜单关闭，方向保持按住后再松开 | 即时停止，无旧映射补发；下次按方向恢复原动作 | 松开补发、陈旧计时器移动或原映射损坏 |
| 应用切换 | 鼠标模式中触发原应用切换键，然后左右选择、确定确认、返回取消 | 退出鼠标模式，原切换器流程保持，Command 正常释放 | 确定变点击、方向变移动或 Command 卡住 |
| 截图回归 | 模式开启及关闭时使用原 TV 等截图键；菜单单击原设截图则分别测试模式内外 | 其他截图键正常；菜单单击仅在模式内右键，退出后恢复截图，原绑定未改写 | 丢失绑定、其他截图键被接管或退出仍右键 |
| 断线恢复 | 分别按住方向或加减键时断开蓝牙，再重连，第一次普通按键和再次开启模式 | 移动与滚动停止，重连默认关闭，首次按键可用 | 自动继续输出或第二次才可用 |
| 权限拒绝 | 未授权时触发切换；移动/滚动中撤销辅助功能/输入监控，再重新授权并重连 | 明确权限阻断，移动与滚动停止；恢复后可重新开启 | 继续输出、静默成功或需要重启电脑 |
| 异常输出 | 自动化令鼠标输出失败，再恢复输出 | 本次模式结束，无残留连发；下一次启用可用 | 无限重试或失败记为目标点击成功 |
| 休眠与取消 | 移动/滚动中锁屏/休眠；切换映射、进入按键捕获或打开常用语 | 停止移动与滚动，旧释放不执行其他动作 | 唤醒继续输出或捕获期间输出 |
| 双设备 | A/B 各自开模式并按方向，断开 A，继续使用 B | 状态与定时器按实例隔离，B 保持有效 | A 断线清空 B 或状态串用 |
| 真实系统边界 | 屏幕四边、多屏跨越、弹窗、不同前台 App | 指针位置、点击目标和权限提示合理 | 指针逃出可用区域、错误点击或跨屏卡住 |

## 稳定回归

- 默认缺少切换绑定、明确设为“不执行”、启用模式、使用后退出四种状态分别验证；保留原映射的单击、双击、长按、按住连发及连续快速按选项。
- RC003 真实 `STREAM_START → AUDIO → STREAM_STOP` 不要求前置主动 MIC_OPEN；语音键不增加双击/长按窗口。
- 极速语音按下/松开 10 次、短句 10 次、快速连续两句、尾字完整、断线/取消/恢复，使用真实虚拟麦克风与目标输入法验证首字和尾字。鼠标功能自动化不能替代语音真机基线。
- 在生产最小/默认 `1020 × 772` 点击全部可见侧边栏，检查按键页面、动作编辑器和鼠标模式状态无裁切、滚动正常、窗口几何不变。覆盖中文/英文、浅色/深色，中文字号至少 12pt。

## 脱敏日志

通过 App 的“文件 → 打开日志目录”收集加密 `.rmlog`，交给内部支持按[日志规范](../LOGGING.md)解密；不要把用户目录、设备标识、屏幕内容或原始日志解密文本粘到公开 PR。

- `MOUSE MODE`：请求、权限拒绝、开启与唯一关闭终态，关闭原因包含用户切换、输入重置、输出拒绝、权限失效、系统挂起或应用切换。
- `MOUSE MOVE`：同一进程内 `operation_id` 的开始、首次事件提交 `first_output_ms` 和聚合停止终态，包含 `submitted_frames` 与 `elapsed_ms`；正常松手后无继续提交。
- `MOUSE SCROLL`：独立的滚轮操作号、首个提交、连发间隔与唯一停止终态，聚合次数和耗时；不得逐帧记录，不含指针坐标或页面内容。
- `MOUSE CLICK`：一次点击一个提交/失败终态，`button=left|right` 区分两种点击；`target_result=unknown` 明确无法自动确认目标 App 是否处理，实机观察才是最终点击结果。菜单旧回调记录 `reason=stale_mouse_mode_generation` 且无点击终态。
- 不逐帧写鼠标日志，不记录鼠标坐标、设备 ID、窗口标题、输入内容或其他 App 私有状态。

## 平台与硬件差异

| 分类 | macOS 小米候选 | 其他硬件 / Windows |
| --- | --- | --- |
| 已对齐 | 原映射保留、普通键 550 ms 长按、重复边沿去重、会话取消、实例隔离 | 苹果/Chromecast 原有链路不修改；不得据此宣称新功能已兼容 |
| 物理不存在 | 小米无触摸面，使用实体方向键、菜单键及音量加减键；本期无拖拽或水平滚轮 | 苹果触摸面维持原功能 |
| 平台不支持 | 无其他 App 私有数据访问 | Windows、手机、Web、Chromecast 与苹果不提供新切换动作 |
| 待验证 | RC001/RC003 真机速度、系统输入、权限恢复、屏幕边缘、双设备与语音基线 | Windows 未实现，所有新鼠标模式实机项未运行 |
