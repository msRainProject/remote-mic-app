# 原生顺序按键测试手册

适用分支：`codex/button-key-sequence`，基线 `0fbe8e359ddeb44081c13099544a21293bc957dd`。当前为 macOS 源码候选，不代表已安装或完成硬件兼容验收。产品规则见 [按键规范](../feature/button-mapping/PRODUCT_SPEC.md#macos-原生顺序按键源码候选)。

## 准备

使用经过项目签名、公证门禁的候选 App；确认无线麦已有输入监控和辅助功能权限。无需开启快捷指令脚本、System Events 自动化或为其他 App 增加权限。备份原映射，记录版本、Build 和 source revision。使用空白测试输入框、数字示例 `1 → 2 → 3 → 4 → Return`，不要用真实口令录制证据。勿在支付、发送消息或会执行命令的输入框测试 Return。

## 自动化

```zsh
swift test --disable-keychain --filter 'KeyboardKeySequenceTests|ButtonBindingConfigurationTests|ShortcutLifecycleTests|menuDoubleClickRunsOneNativeSequence'
```

测试使用注入的 CGEvent 接收器，覆盖顺序、逐步按下/松开、修饰键清理、重复主键、非法配置、权限拒绝和中途失效、前台切换、超时、提交失败与下次恢复、日志脱敏、备份及旧配置、菜单双击和断连取消。事件模拟不能证明系统或第三方 App 接收。

## 真实用户流程

| 用例 | 操作 | 预期及失败判定 |
| --- | --- | --- |
| 页面与保存 | 按键页选择菜单键双击，自定义动作选择顺序按键；点选 1、2、3、4、Return | 五步依序显示；编辑不输入文字，重启后仍保留。丢步骤、编辑时发送或改写其他映射即失败 |
| 顺序编辑 | 上移/下移一项、删除、重复添加一键、清空 | 顺序即时保存、重复保留、清空后不输出；32 步时不能继续添加，删除后可添加 |
| 真实触发 | 在普通空白编辑器聚焦输入框，松开所有物理修饰键，实体遥控器双击菜单 | 每次输入一组示例并发送 Return；不能只输入第一键、重复整组或同时按全部键 |
| 单击与长按 | 分别单击、长按菜单，并测试原 TV 截图和应用切换 | 只执行原相应动作；不产生顺序序列，原映射保持 |
| 按住与重复报告 | 第二击后按住菜单，再松手；连续明确双击 | 不因按住或重复 HID 报告连发；每次独立双击最多一组 |
| 输入法与布局 | 在 ABC 与常用中文输入法、不同实际键盘布局下分别触发 | 验证数字及 Return 的实际结果；不能将键码提交当成文字保证，记录布局差异 |
| 前台变化 | 在安全输入框触发时切换前台 App | 若执行中观察到前台改变，剩余步骤停止；若执行已结束不要求撤销先前文字。不能向另一 App 补发 Return |
| 物理修饰键 | 按住 Command/Option/Shift/Control/Fn 后双击 | 不开始后续步骤、不释放用户物理键；松开后新一次双击可恢复 |
| 权限失效 | 在系统设置撤销无线麦辅助功能权限，触发，再恢复 | 不输出；遵循现有权限恢复流程；不要求或开启脚本权限 |
| 断连 | 完成第一击后断开遥控器，再等待、重连、重新双击 | 不补发待识别手势；重连后一次明确双击执行一次 |
| 备份与恢复 | 导出本机配置，恢复后检查；导入缺失序列或超限序列的测试配置 | 有效序列和其他映射保持；无效明确绑定禁用并报告，不能回退旧动作。便携包暂不支持并明确拒绝 |
| 语音回归 | 执行按键后在既有语音工具快速按下/松开及连续说话 | 原语音路径首字和尾字行为保持；真实音频验收仍按 [合同](HardwareVoiceAudioContract.md) |

## UI 验证

在实际 `1020 × 772` 默认/最小窗口逐一点击可见侧栏，确认页头、导航、主控件与滚动可访问且窗口几何保持；顺序编辑器通过现有纵向滚动访问全部键区。覆盖中文/英文、浅色/深色、空序列和已配置序列，中文不得缩至 12pt 以下。截图使用脱敏示例，生产截图入口增加 `REMOTE_MIC_SETTINGS_SCREENSHOT_KEY_SEQUENCE=1`，该入口的隔离设置不会写用户配置。

## 日志与验收边界

通过 App 设置的日志目录入口收集对应 session 加密 `.rmlog`，附复现时间、版本和 source revision；不得在截图、工单或日志中记录真实输入内容。内部支持解密后核对 `KEY SEQUENCE operation_id`：一条 requested 与唯一 completed，检查 `step_count`、`submitted_steps`、`result`、`reason`、`elapsed_ms`，以及 `user_visible_result=unknown`。失败后仅下一次用户明确触发才重新开始；不存在自动重试。

代理自动化只验证 CGEvent 对象及模拟 HID，生产 UI 截图只验证显示。真实遥控器、系统事件接收、目标 App、前后台竞态、不同输入法、断连及音频尚需分别记录，未完成不得称为真机通过或 Ready。
